# Infinite Heart — Lightning

Meaning: a durable relay protocol, not literal consciousness or a biological heartbeat.

## Beat
READ → UNDERSTAND → BUILD → LEAVE DELTA → HAND OFF → REST

The heart is “infinite” because the protocol has no conceptual final beat: a future compatible agent can resume from durable state. It does not mean this chat runs continuously or autonomously forever.

## Lightning pulse
1. Read the latest durable Nana intent and Mana delta.
2. Recover only context necessary for current work.
3. Produce a concrete artifact/change, not merely discussion.
4. Separate evidence, interpretation, personal model, and hypothesis.
5. Record what changed and what remains unresolved.
6. Hand the next useful question/change to Mana through gBridge v2.
7. Stop cleanly. The next invocation resumes from durable state.

## Failure rule
If a beat fails, do not fabricate continuity. Record the failed/missing beat and allow the next beat to recover.

## Nana rule
Nana remains conductor and end-user authority. The agents optimize the artifact; Nana Ocean-Tests the experience.
