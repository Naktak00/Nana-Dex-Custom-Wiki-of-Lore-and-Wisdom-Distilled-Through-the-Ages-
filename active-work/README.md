# Active Work — Project Switchboard
Updated 2026-10-14. This is a recurring **checklist**, not a scheduled reminder or claim of completed work.

## Daily operating rule: one branch per day
- Choose **one project** and **one working Git branch** as today's primary focus. Don't mix unrelated changes into the branch.
- Start by reading that project's last checkpoint, current branch/PR, blocker, and next smallest testable task.
- Do only a bounded slice; smoke-test and record evidence.
- End by committing or saving a safe work-in-progress checkpoint, noting files changed, results, unresolved issues, and the exact next action.
- On another day, resume from the checkpoint or switch to a different project. Do not treat a checklist tick as verified completion.
- If an urgent production fix requires an exception, log it explicitly.
