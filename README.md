# Nana-Dex
## Custom Wiki of Lore and Wisdom Distilled Through the Ages

**Version:** 2.0 — Mana Retrofit Pass  
**Status:** Living public wiki  
**Core rule:** *Reality gets veto power.*

Nana-Dex is a working atlas for studying how stories, philosophies, religions, symbols, technologies, and human experience change as they pass through time.

It is deliberately not a book of unquestionable answers. Every claim should remain visibly sorted by evidence status:
- **Attested** — directly supported by a source.
- **Interpretation** — a reasoned reading of evidence.
- **Personal model** — a useful framework created for this project.
- **Hypothesis** — an idea worth testing, not a finding.
- **Unsupported** — a claim that currently lacks adequate evidence.

## Public Boundary
This repository is public. It may contain research notes, interpretive models, field notes, and schemas. It should not contain private teachings, credentials, personal secrets, or claims that require Nana's full private story to understand.

Nana has the full story. Lightning has the Library. Mana's role in this pass is to help retrofit the Library so it can scale without confusing wonder for proof.

## The Nana-Dex Loop
**Encounter → Observe → Name → Classify → Compare → Test → Preserve → Transmit → Revisit**

A beautiful model is allowed to remain beautiful. It is not allowed to impersonate evidence.

## Design Principle
> Origin ≠ Destiny. Identity ≠ Prison.
