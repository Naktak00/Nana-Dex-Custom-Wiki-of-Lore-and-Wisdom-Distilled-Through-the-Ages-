# Templates

Use these schemas when creating or expanding Nana-Dex pages:

- [Entity](ENTITY.md): gods, demons, spirits, archetypes, symbols, and named figures.
- [Text](TEXT.md): grimoires, books, manuscript traditions, corpora, editions, and translations.
- [Concept](CONCEPT.md): Nana-Dex models and reusable interpretive tools.
- [Field note](FIELD-NOTE.md): bounded lived observations with causal and personal layers separated.
- [Source record](SOURCE.md): source metadata and what a source can actually support.

Templates are scaffolds, not cages. Remove empty sections only when the omission is deliberate.
