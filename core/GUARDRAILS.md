# Epistemic Guardrails

## Prime Rule
> **Reality gets veto power.**

If a model repeatedly fails evidence, revise or discard it.

## Classification Marks
- 🟢 **Attested** — directly supported by a source.
- 🔵 **Interpretation** — reasoned reading.
- 🟣 **Personal definition/model** — meaningful by declared convention.
- 🟡 **Hypothesis** — plausible but unconfirmed.
- 🔴 **Unsupported** — currently lacks adequate evidence.

## Similarity Rule
> Similarity earns comparison. It does not establish ancestry.

This is especially important for gods, demons, serpents, dragons, symbols, names, and cross-cultural archetypes.

## Sacred ≠ Empirical
Evidence can challenge beliefs about external reality. It cannot dictate what a person is required to hold sacred.

Likewise, sacred value does not automatically establish an external factual claim.

## Safety Rule
> Not every truth needs to be personally tested.

Fear can be information without becoming sovereign. Courage does not require disabling self-preservation.

## Wonder Rule
> Never sacrifice truth for wonder.

The goal is not to make the world less strange. It is to make our descriptions more honest.
